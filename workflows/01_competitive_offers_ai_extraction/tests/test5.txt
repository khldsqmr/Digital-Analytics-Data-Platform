One judgment call worth flagging: media_analytics_paid_search has a Display - Discovery row (DDIS, ~$36.5M) tagged Channel_Group_Name = 'Display', not 'Paid Search'. The actual CASE logic ends up simple:

sql
CASE
  WHEN raw.Channel_Group_Name = 'Paid Search'                                          THEN 'Paid Search'
  WHEN raw.Channel_Group_Name = 'Paid Social'                                          THEN 'Paid Social'
  WHEN raw.Channel_Group_Name IN ('Display', 'Online Video', 'Digital Audio', 'OTT')   THEN 'Programmatic'
  WHEN raw.Channel_Group_Name = 'National TV'                                          THEN NULL  -- excluded pending scope decision
  ELSE 'Other'  -- Affiliate, UNKNOWN, Other, Out of Home
END AS channel_group
